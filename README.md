# IT9201 Machine Learning and Data Mining Project

## Project Title
Short-Term Electricity Consumption Prediction for Smart City Building Using Machine Learning

## Description
This project predicts next-hour net electricity consumption for a smart building using classical machine learning models.

## Models Used
- Linear Regression
- Elastic Net Regression
- Random Forest
- XGBoost

## Dataset
The dataset is the Dryad smart company building energy dataset:
https://doi.org/10.5061/dryad.73n5tb363

## Main Outputs
- Preprocessing and feature engineering
- Model training and hyperparameter tuning
- Model evaluation using MAE, RMSE, R², MedianAE, and P95AE
- TreeSHAP interpretability
